What is Dropsite?

Dropsite hosts static websites instantly. Upload a zip of your HTML/CSS/JS project and get a live URL in seconds. Perfect for portfolios, landing pages, prototypes, and demos.

How to Deploy

  1. Zip your project
    Make sure index.html is in the root of the zip, not inside another folder. Include all CSS, JS, images.
  2. Log in to Dropsite
    Go to /login.html. Use "Sign Up Free" if you're new, or "Log In" if you already have an account. Enter email → Click magic link in inbox.
  3. Drag & drop
    Drop the .zip file onto the Dropsite dashboard. Max 100MB free, 500MB premium.
  4. Copy your URL
    Dropsite gives you a live link instantly. Share it anywhere.

Troubleshooting

"Email rate limit exceeded"

Supabase only allows 3-4 magic links per hour per email. Wait 1 hour and try again. This protects against spam.

Site shows 404

Your zip must have index.html at the root level. If your file is in mysite/index.html, move everything up one level before zipping.

Images/CSS not loading

Use relative paths like ./style.css or images/logo.png not absolute paths like /style.css
